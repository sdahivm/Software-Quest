Hardware es la parte física del computador: monitor, teclado, mouse, disco, etc.

Software es la parte lógica: programas e instrucciones que le indican al hardware qué hacer.

NIVEL 3 · TIPOS DE LICENCIA

Conoce las licencias

Primero identifica las características de cada licencia. Después, aplica lo aprendido en un reto.

G

GPL

Licencia de software libre

Permite usar, modificar y distribuir el software. Cuando se distribuye una versión modificada, debe mantenerse bajo la misma licencia GPL.

Idea clavePuedes modificar y compartir el software, manteniendo las mismas libertades.
M

MIT

Licencia permisiva

Permite usar, modificar y distribuir el software con pocas restricciones. También puede utilizarse en proyectos comerciales, respetando sus condiciones.

Idea clavePermite reutilizar y adaptar el código con bastante libertad.
P

Propietaria

Software con restricciones

El software pertenece a un propietario, quien establece las condiciones de uso, modificación y distribución. Generalmente, el código fuente no está disponible para ser modificado libremente.

Idea claveEl propietario mantiene el control sobre el software y sus condiciones de uso.
D

Dominio Público

Sin derechos exclusivos aplicables

La obra o software se encuentra disponible sin derechos exclusivos de autor aplicables, por lo que puede utilizarse, modificarse y distribuirse libremente.

Idea claveNo existen derechos exclusivos de autor aplicables que limiten su uso.
