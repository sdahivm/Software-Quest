NIVEL 3

Conoce las licencias

Lee las características y después identifica la licencia en situaciones de desarrollo.

GPL

Software libre

Permite usar, modificar y distribuir el software. Cuando se distribuye una versión modificada, debe mantenerse bajo la misma licencia GPL.

Idea clave: mantener las mismas libertades.

MIT

Licencia permisiva

Permite usar, modificar y distribuir el software con pocas restricciones. También puede utilizarse en proyectos comerciales, respetando sus condiciones.

Idea clave: reutilizar y adaptar con bastante libertad.

Propietaria

Software con restricciones

El propietario establece las condiciones de uso, modificación y distribución. Generalmente, el código fuente no está disponible para ser modificado libremente.

Idea clave: el titular mantiene el control.

Dominio Público

Sin derechos exclusivos aplicables

La obra o software se encuentra disponible sin derechos exclusivos de autor aplicables, por lo que puede utilizarse, modificarse y distribuirse libremente.

Idea clave: no hay derechos exclusivos de autor aplicables que limiten su uso.
